# Zaha Kitchen — Authentic Chai & Artisan Snacks

Luxury dining and tea house web application built for **Zaha Kitchen** in Ernakulam & Infopark IT Hubs, Kochi.

## Features
- **105-Item Interactive Menu Page**: Complete dining menu across 8 categories (Breakfast Specials, Naadan Meals, Non-Veg Roasts, Malabar Dum Biriyani, Thalis, Evening Snacks, Hot Beverages, Cold Refreshments & Mojitos).
- **Dual Menu Layout Modes**: Compact Menu Sheet (classic dot-leader layout) and Grid Card Mode.
- **Dietary & Search Filters**: Instant search bar with filters for Pure Veg 🟢, Non-Veg 🔴, and Bestsellers ★.
- **Scroll-Driven Hero Experience**: High-performance canvas sequence with Lenis inertial smooth scrolling.
- **Catering & Reservations**: Custom catering inquiry and table reservation form system.

## Tech Stack
- **Framework**: React 19 + TypeScript
- **Build Tool**: Vite 8
- **Styling**: Vanilla CSS, Responsive Glassmorphism, Google Fonts (Outfit & Playfair Display)
- **Animations**: GSAP, ScrollTrigger, Lenis
- **Icons**: Lucide React
